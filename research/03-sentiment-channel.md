# 短线精灵：情绪周期复盘频道

看板第三个主 Tab，回答前两页不回答的问题——**今天冷不冷、有没有主线、值不值得出手**。
第一页看「有多热」（指数层面），第二页看「贵不贵」（估值层面），第三页看「市场里的人和事」。

## 一、情绪温度

```
温度 = 50% × 上涨家数占比(%)
     + 30% × min(涨停家数, 100)
     + 20% × max(0, 100 − 跌停家数 × 10)
```

三个子项都是 0–100 的原始刻度，无需再转分位。分档：

| 区间 | 档位 | 含义 |
|---|---|---|
| < 20 | 冰点 | 恐慌出清区，通常伴随跌停潮或地量 |
| 20–40 | 低温 | 退潮期，赚钱效应缺失 |
| 40–60 | 中性 | 常态拉锯 |
| 60–80 | 升温 | 赚钱效应扩散 |
| ≥ 80 | 亢奋 | 过热，注意高度股断板负反馈 |

**不预测方向。** 温度回答"现在多冷"，不回答"明天涨不涨"。它的价值在于区分「阴跌式退潮」与「崩溃式冰点」——
前者缩量、跌停少、可以在低成交下持续很久；后者放量、跌停扩散、往往对应可交易的底部。区分依据是
**跌停家数 + 成交额占 120 日均值比重**，两者同时满足才叫出清。

## 二、数据源与口径分层

本频道有两个日期，**不可混读**，页面已分别标注：

| 层 | 板块 | 日期 | 接口是否支持历史 |
|---|---|---|---|
| 复盘层 | 情绪温度 / 涨跌宽度 / 连板梯队 / 龙虎榜 | 最近一个**已收盘**交易日 T | 支持 `--date` |
| 实时层 | 板块强弱（行业 / 概念） | 抓取时刻最新快照 | **不支持**，实时榜忽略 `--date` |

接口映射：

| 数据 | 命令 |
|---|---|
| 指数收盘 / 成交额 / 宽度 / 技术 / 估值 | `market-overview --type all --date T` |
| 六日情绪脉搏 | `market-overview --type updown --date T-i` × 6 |
| 连板梯队 | `screen ranking --type limitup_days --date T --limit 120` |
| 个股换手 / 成交额 / 20 日涨幅 | `quote <codes> --date T` |
| 龙虎榜全量 / 机构专用席位 | `lhb --type all|institution --date T` |
| 板块强弱 | `sector ranking --kind industry|concept` |
| 交易日 / 月末标记 | `trade-calendar --market hs` |

## 三、踩过的坑（都会影响正确性）

1. **`sector ranking` 的实时榜忽略 `--date`。** 帮助原文：「实时榜（industry/concept）按涨跌幅/成交额/主力资金排序；
   `--date` 仅用于区间涨跌幅榜（chg5d/chg20d/…）」实测 10-28、10-29、10-20 三个日期的返回值完全一致，
   且与无日期调用相同，确认为实时快照。**不能拿它复现历史板块截面**，因此单列为实时层。

2. **`lhb --type institution` 同一只票会出现多行。** 分别对应 1 日榜与 3 日榜（`tdDays` 字段）。
   不去重会重复计数（10-29 原始 40 行、去重后 37 只）。处理方式：按代码去重，优先保留 `tdDays == 1`。

3. **`instBuyAmt` 是有符号的机构净买入额**，买入端与卖出端共用同一字段。
   光库科技 `+1.5749 亿`、天孚通信 `−4.8176 亿`，直接按正负分列即可，不要另找"卖出额"字段。

4. **`market-overview --type margin` 当日通常为空**（两融按 T+1 披露）。不要用前值填充，
   那会把"当日成交额 ÷ 昨日融资额"算成一个虚高的杠杆率（曾出现 8.91% vs 真实 8.52%）。本频道直接不纳入两融。

5. **盘中必须沿用上一交易日。** 连板梯队与龙虎榜在收盘后才定稿，盘中取当日会得到残缺数据，
   算出的温度偏低且不可比。`resolve_target()` 以 15:05 为界：之前取上一交易日，之后取当日。

6. **前端：`innerHTML` 重建会让 echarts 实例绑在已脱离文档的旧节点上。**
   表现为图表区域一片空白、DOM 里既没有 `<canvas>` 也没有 `_echarts_instance_`。
   处理：记录 `schartDom`，节点变了就 `dispose()` 后重新 `init()`。

## 四、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sentiment` | 返回缓存的情绪复盘数据 |
| POST | `/api/sentiment/refresh` | 重新取数并计算，返回新数据与耗时 |

与指标刷新（`/api/refresh`）**互不依赖**：两把锁、两套数据。情绪刷新实测 10–15 s（六日脉搏有本地缓存后约 10 s）。

## 五、文件

| 文件 | 作用 |
|---|---|
| `scripts/sentiment.py` | 取数 + 计算 + 文案规则，产出 `data/senti/sentiment.json` |
| `data/senti/pulse_cache.json` | 六日脉搏的按日缓存（历史交易日不会变） |
| `scripts/tpl.html` | 第三页 `#pane3` 的骨架、样式与渲染函数 |
| `scripts/build_dashboard.py` | 把 `sentiment.json` 注入模板的 `/*__SEN__*/null` |

## 六、与独立报告的关系

`2026-10-30` 工作区里那份《A 股情绪周期复盘_2026-10-29》是同一套方法论的**单次静态产出**，
带完整长文判断；本频道是它的**可刷新版本**，判断文案改为规则生成，因此措辞更短、更机械，
换来的是每天点一下就能更新。两处口径一致：温度 31.8、涨停 36 / 跌停 3、连板 39 只、最高 4 板、机构净卖出前五 −14.81 亿。
