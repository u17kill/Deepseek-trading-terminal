# 美股精灵频道 · 口径与数据源

第四页「美股精灵」，对应 `scripts/us_senti.py`。
与第三页「短线精灵」（A 股）并列，但两套口径完全独立，**不可混读**。

## 一、为什么不能和 A 股温度并列比较

| | A 股短线精灵 | 美股精灵 |
|---|---|---|
| 情绪指标 | 自建温度 = 0.5×上涨占比 + 0.3×min(涨停,100) + 0.2×max(0,100−跌停×10) | CNN Fear & Greed（7 分项合成） |
| 取值范围 | 0–100 | 0–100 |
| 含义 | 涨停强度主导 | 期权、波动率、债市利差、宽度综合 |

两组数字都落在 0–100，但**没有任何共同刻度**。放在一张图上比高低是错误用法，
只能各自看自己的趋势。

## 二、八个模块

### ① 恐惧贪婪（CNN）

接口 `https://production.dataviz.cnn.io/index/fearandgreed/graphdata`

必须带完整浏览器头，缺 `Referer` 或 `Origin` 会返回反爬页面；
同时 `requests.Session().trust_env = False` 绕开系统代理。

返回结构：
- `fear_and_greed`：总分、rating、前收盘/前一周/前一月/前一年
- `fear_and_greed_historical.data`：251 个点，约 1 年
- 7 个分项各含 `score` / `rating` / `data`

七个分项及含义：

| 键 | 名称 | 说明 |
|---|---|---|
| `market_momentum_sp500` | 市场动能 | 标普500 相对 125 日均线 |
| `stock_price_strength` | 股价强度 | 52 周新高与新低家数对比 |
| `stock_price_breadth` | 市场宽度 | 上涨股成交量占比（McClellan） |
| `put_call_options` | 看跌看涨比 | 5 日平均 put/call |
| `market_volatility_vix` | 市场波动 | VIX 相对自身 50 日均线 |
| `junk_bond_demand` | 垃圾债需求 | 高收益债与国债利差 |
| `safe_haven_demand` | 避险需求 | 股票与国债 20 日收益差 |

**只取最新读数，不做历史分位**：251 个点不足以支撑有意义的长期分位。
每日存一份到 `data/us_senti/fng_archive.json`，攒够样本再谈分位。

分档：<25 极度恐惧、25–45 恐惧、45–55 中性、55–75 贪婪、>75 极度贪婪。

### ② 涨跌榜

四个池子：道指 `us.DJI`(30) + 标普500 `us.SPX`(503) + 纳指100 `us.NDX`(101)
+ 中概 `universe --market us --type china_stock`(466)。

**去重后 518 只**（纳指 100 与道指的成分几乎全部包含在标普 500 内），中概另计。

中概必须过滤：全池 466 只里大量粉单与仙股，实测涨幅第一 `usSEII` 涨 100%、
成交额 0、市值 0。按成交额 ≥ 500 万美元过滤后剩 71 只。
门槛写在 `CN_MIN_AMT`。

榜单剔除名称含 `ETF` / `ETN` 的品种。

### ③ 板块热力

11 只 SPDR 行业 ETF：XLK 科技、XLF 金融、XLE 能源、XLV 医疗保健、XLI 工业、
XLY 非必需消费、XLP 必需消费、XLU 公共事业、XLB 基础材料、XLRE 房地产、XLC 通讯服务。

取当日、5 日、20 日、60 日、年初至今，以及 52 周位置
= (现价 − 52周低) ÷ (52周高 − 52周低)。

### ④ 涨跌家数

四池分别统计 + 去重合计。美股无涨跌停，A 股的「涨停/跌停」这一项换成
**涨跌超 5% 的家数**，含义接近（极端个股的赚钱与亏钱效应）。

### ⑤ 防御 vs 进攻

防御 = XLU + XLP + XLV，进攻 = XLK + XLY + XLC，各组等权合成净值后取比值。
曲线以 120 日前的 100 为起点。比值上行 = 资金往防御躲（risk-off）。

另给 5/20/60 日相对收益（百分点）。

### ⑥ Mag7 贡献度

AAPL、MSFT、NVDA、GOOGL、AMZN、META、TSLA。
按市值加权算平均涨跌，与 QQQ 实际涨跌对比：

- Mag7 明显强于 QQQ → 拖累来自七巨头之外的中小成分
- Mag7 明显弱于 QQQ → 巨头在砸盘

贡献 = 个股市值权重 × 个股涨跌，正负相抵等于加权涨幅。

### ⑦ 半导体相对强弱

SOXX ÷ SPY，120 日曲线，起点 100。已剔除大盘影响，
比单看 SOXX 涨跌更能说明"资金愿不愿意承担高波动"。

### ⑧ 52 周新高新低

现价距 52 周高点 0.5% 内计为新高，距低点 0.5% 内计为新低。
只统计美股主池（518 只），中概 ADR 的 52 周口径不齐，不纳入。

另给全池在 52 周区间中的中位位置，判断整体处在高位还是低位。

## 三、交易日与时段

- 美股 09:30–16:00 ET = 北京时间 21:30–04:00（夏令时）/ 22:30–05:00（冬令时）
- 用 `zoneinfo` 转美东时间判断 `in_session`，页面标「盘中快照」或「已收盘」
- 数据日期取批量 quote 返回的 `time` 字段（交易所有交易日），而不是本地日期

## 四、接口

```
GET  /api/us_senti           缓存
POST /api/us_senti/refresh   重取（独立锁 _us_lock，不阻塞 A 股刷新）
```

页面 hash：`#us` 直达。

刷新耗时约 10.5 秒：3 次成分股 + 2 次批量 quote（518 只 / 1.4s、466 只 / 1.2s）
+ 1 次 ETF/Mag7 quote + 8 次 kline（5 线程并行）+ CNN。

## 五、运维提醒

**改完 `scripts/us_senti.py` 必须重启 `server.py`。**
服务进程里 import 的是启动时的模块，点「刷新美股」会用旧代码重新 build
并覆盖 json —— 表现是"改了没生效"，实际是被旧进程写回去了。
