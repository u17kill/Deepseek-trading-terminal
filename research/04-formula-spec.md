# 指数超买超卖指标 —— 完整计算公式规范（用于第三方复验）

> 版本：v4（2026-10-29 起生效，拥挤模块重构）
> 标的：科创50（sh000688）、创业板指（sz399006）
> 标度：全部子项统一转为 0–100 的滚动分位，最终总分 0–100，越大越「超买/过热」

---

## 0. 输入数据与通用函数

### 0.1 输入字段（日频，按交易日升序）

| 字段 | 含义 | 单位 |
|---|---|---|
| `date` | 交易日 | YYYY-MM-DD |
| `open/high/low/close` | 指数 OHLC | 点 |
| `volume` | 成交量 | 手 |
| `amount` | 该指数当日成交额 | 元 |
| `turnover` | 该指数换手率 | % |
| `amt_all` | 两市成交额 = 上证指数(sh000001).amount + 深证成指(sz399001).amount | 元 |

数据源：腾讯自选股 westock 日线。样本区间 2021-01-01 起，约 1400 个交易日。

### 0.2 分位函数 PR（最关键，务必按此实现）

```
PR(x, w=250) = x.rolling(window=w, min_periods=175).rank(pct=True) * 100
```

含义：对每个交易日 t，取**含当日在内、向前 250 个交易日**的窗口，计算当日 x_t 在该窗口内所有非空值中的百分位排名，再乘 100。

实现要点：

1. **必须用滚动窗口**（trailing 250），**不是全样本排名**。这是最常见的复验失败原因。
2. `min_periods = 175`（即 `int(250*0.7)`），窗口不足 175 个有效值时不计算（返回 NaN）。
3. `rank(pct=True)` 返回「排名 / 有效值个数」，并列值取**平均排名**（pandas 默认 `method='average'`）。
4. 取值范围不是 0–100 而是 **100/n ~ 100**。n=250 时最小值约 0.4，所以正常读数下限是 0.4 而不是 0。

### 0.3 均线与标准差

```
MA20 = close.rolling(20).mean()
SD20 = close.rolling(20).std()        # ddof=1，样本标准差，pandas 默认
```

前 19 行为 NaN。全文所有 20 日统计量均使用 ddof=1。

## 1. 位置模块（权重 40%）

回答「价格在历史分布里的什么位置」，三个子项，全部先算原始值再做 PR。

### 1.1 三个原始量

**(a) 20 日乖离率 BIAS20**

```
BIAS20 = close / MA20 - 1          # 小数
展示值 = BIAS20 * 100              # 百分比
```

**(b) 布林带内位置 BOLLPOS**

```
BOLLPOS = clip( (close - (MA20 - 2*SD20)) / (4*SD20), 0, 1 )
展示值 = BOLLPOS * 100             # 0=下轨, 100=上轨
```

分母恒为 `4*SD20`（上下轨间距），所以 BOLLPOS=0.5 表示在中轨。**必须 clip 到 [0,1]**，超出 2 倍标准差的极值被截断在中轨两侧边界，防止极端值污染分位。

**(c) 距 250 日高点回撤 DD250**

```
DD250 = ( close / close.rolling(250, min_periods=120).max() - 1 ) * 100
```

注意窗口 `min_periods=120`（不是 175、不是 250），且结果 **≤ 0**（当日即最高点时为 0）。

### 1.2 合成

```
s_bias = PR(BIAS20)
s_boll = PR(BOLLPOS)
s_dd   = PR(DD250)

s_pos = 0.40*s_bias + 0.30*s_boll + 0.30*s_dd
```

DD250 全为负值，但 PR 是相对排名，越接近 0（离高点越近）分位越高，故方向正确。

## 2. 拥挤模块（权重 35%）

回答「交易有多激烈」。v4 口径，三个子项：

### 2.1 三个原始量

**(a) 成交额占两市比重 SHARE**

```
SHARE = amount / amt_all * 100      # 百分比
SHARE = SHARE.ffill()               # 前值填充，对齐节假日/停牌
```

这是**分量占比**而非绝对成交额，因此不受市场规模扩张影响。

**(b) 20 日已实现波动率 VOL20**

```
ret   = close.pct_change()
VOL20 = ret.rolling(20).std()       # ddof=1，小数
展示值 = VOL20 * 100                # 百分比
```

**(c) 换手率 TURNOVER**，直接取原始字段。

### 2.2 合成

```
s_share = PR(SHARE)
s_vol   = PR(VOL20)
s_turn  = PR(turnover)

s_crowd = 0.50*s_share + 0.30*s_vol + 0.20*s_turn
```

### 2.3 已剔除的子项（复验时不要加回去）

| 子项 | 与位置模块相关性 | 处置 |
|---|---|---|
| 成交额 / 20 日均额 | 0.60 / 0.54 | 剔除 |
| 20 日量价相关性（close 涨跌幅 vs 换手率变化） | — | 剔除 |
| 融资买入额占成交额（两融） | **0.64 / 0.65** | **剔除**，仅作观察项 |

两融被剔除的理由：杠杆天然追涨，是价格的影子，不构成独立维度。

### 2.4 降级逻辑（仅在缺少 `amt_all` 时触发，正常不执行）

```
s_amt = PR(amount / amount.rolling(20).mean())
pv    = close.pct_change().rolling(20).corr(turnover.pct_change())
s_crowd = 0.50*s_turn + 0.30*s_amt + 0.20*((pv.clip(-1,1)+1)*50)
```

## 3. 动能模块（权重 25%）

回答「正在往哪个方向走、走得多快」。

### 3.1 RSI6（Wilder 平滑）

```
d  = close.diff()
ag = d.clip(lower=0).ewm(alpha=1/6, adjust=False).mean()      # 平均涨幅
al = (-d).clip(lower=0).ewm(alpha=1/6, adjust=False).mean()   # 平均跌幅
RSI6 = 100 - 100 / (1 + ag / al)
# 实现上 al 为 0 时替换为 1e-12，避免除零
```

`adjust=False` 表示递推式指数平滑（首值作为种子），不是简单移动平均。

### 3.2 10 日风险调整收益 RA10

```
RA10 = ( close / close.shift(10) - 1 ) / ( VOL20 * sqrt(10) )
```

VOL20 即 2.1(b) 的 20 日日收益标准差。除以 `VOL20*sqrt(10)` 是把 10 日累计收益按其波动率标准化。

### 3.3 合成

```
s_mom = 0.50 * RSI6 + 0.50 * PR(RA10)
```

**注意不对称性**：RSI6 本身已是 0–100 标度，**直接使用原始值，不再做 PR**；只有 RA10 做分位化。这是全公式里唯一不做分位变换的子项。

## 4. 总分与分档

### 4.1 加权合成

```
raw = 0.40*s_pos + 0.35*s_crowd + 0.25*s_mom
```

### 4.2 3 日平滑（EMA，α=0.5）

```
score = raw.ewm(span=3, adjust=False).mean()
```

`span=3, adjust=False` 等价于 `alpha = 2/(3+1) = 0.5` 的递推平滑：

```
score_t = 0.5 * raw_t + 0.5 * score_{t-1}
```

**这是复验最容易出错的地方**：页面上展示的总分是 `score`，而展示的三个模块分是未经平滑的 `s_pos / s_crowd / s_mom`。因此

```
0.40*s_pos + 0.35*s_crowd + 0.25*s_mom  ≠  页面总分
```

差额完全来自这一步 EMA 平滑，不是计算错误。

### 4.3 分档阈值

```
pd.cut(score, [-0.1, 15, 30, 70, 85, 100.1],
       labels=["极端超卖","警戒超卖","正常","警戒超买","极端超买"])
```

区间为左开右闭：`score ≤ 15` → 极端超卖；`15 < score ≤ 30` → 警戒超卖；`30 < score ≤ 70` → 正常；`70 < score ≤ 85` → 警戒超买；`score > 85` → 极端超买。

### 4.4 输出取整

所有展示值四舍五入到 **1 位小数**。

## 6. 复验时的 8 个易错点

1. **PR 是滚动窗口排名，不是全样本排名。** 用全样本算会得到完全不同的数。
2. **PR 的 min_periods=175**，不是 250。窗口不足 175 个值应为 NaN。
3. **DD250 的 min_periods=120**，唯独这一项是 120。
4. **BOLLPOS 必须先 clip 到 [0,1] 再分位化**，顺序不能颠倒。
5. **RSI6 不做分位化**，直接用 0–100 原始值；其余所有子项都分位化。
6. **RSI 用 Wilder 平滑（ewm alpha=1/6, adjust=False）**，不是简单均值，也不是 α=1/6 的 adjust=True。
7. **页面总分是 EMA(α=0.5) 平滑后的值**，三模块加权和与之不等，差值来自平滑，属正常。
8. **std 全部用 ddof=1**（样本标准差）。

## 7. 一句话总结

```
score_t = 0.5*raw_t + 0.5*score_{t-1}

raw_t = 0.40*s_pos + 0.35*s_crowd + 0.25*s_mom

s_pos   = 0.40*PR(C/MA20-1) + 0.30*PR(clip((C-(MA20-2SD20))/(4SD20),0,1)) + 0.30*PR((C/MAX250-1)*100)

s_crowd = 0.50*PR(amount/amt_all*100) + 0.30*PR(std(ret,20)) + 0.20*PR(turnover)

s_mom   = 0.50*RSI6 + 0.50*PR((C/C[-10]-1)/(std(ret,20)*sqrt(10)))

PR(x) = x.rolling(250, min_periods=175).rank(pct=True)*100
```

（`MA20/SD20` 为 20 日简单均值与样本标准差；`MAX250` 为 250 日最高收盘，min_periods=120；`RSI6` 为 Wilder 6 日 RSI）

## 8. 附：美股 QQQ / SOXX 的口径差异

位置与动能两个模块**与上面完全相同**，不差分毫。只有拥挤模块换了两个子项，因为美股 ETF 拿不到 A 股那两个字段：

| A 股子项 | 美股替代 | 理由 |
|---|---|---|
| 成交额 ÷ 两市成交额 | **成交额 ÷ SPY 成交额** | 美股没有「全市场成交额」口径；SPY 是全市场流动性锚，作分母可保持「份额」语义 |
| 换手率分位 | **成交量分位** | westock 对美股 ETF 的 `turnover_rate` 恒为 0、无股本字段；ETF 份额申赎缓慢，成交量分位 ≈ 换手率分位 |

拥挤权重不变，仍是 `0.50*PR(份额) + 0.30*PR(VOL20) + 0.20*PR(成交量)`。

**独立性检验**（与位置模块相关性，QQQ / SOXX）：

| 候选 | 与位置 | 处置 |
|---|---|---|
| 成交额 / SPY 成交额 | **−0.06 / 0.01** | 采用（比 A 股的 0.26 更独立） |
| 20 日波动率 | −0.47 / −0.28 | 采用（美股高波动对应下跌，方向与 A 股相反，属正常） |
| 成交量分位 | −0.32 / −0.15 | 采用 |
| 成交量 / 20 日均量 | −0.28 / −0.15 | 未采用 |

**数据清洗（复验时必须先做）**：westock 返回的 2022-03-08 之前的 `volume` 与 `amount` 均为真实值的 **100 倍**（`amount/(volume*close)` ≈ 100，之后恒为 1）。不除 100 会让滚动分位在断点处严重失真。

**样本限制**：美股数据自 2022-01-03 起，经 250 日窗口预热后有效样本自 **2023-03-13** 开始，共 **896 个交易日**。样本内 QQQ 的分数 86.2% 落在「正常」档，**极端超卖一次都没出现过**，因此美股读数不具备识别底部的样本基础。
