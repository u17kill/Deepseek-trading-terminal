## 1. 产品定位

终端里已有两个页面回答「人」的问题：**最新风向**答「某一个人最近说了什么」，**大佬持仓**答「账上到底有什么」。本模块回答第三种问题：

> **一类机构对一类资产，判断是什么。**

差别在维度。人是独立的观点流，机构是有分工的——高盛不做印度光伏尽调，KKR 不做 A 股行业配置。因此本模块的基本形态不是时间流，而是**矩阵**：

- **横轴**：谁在看（机构）
- **纵轴**：看什么（主题）
- 两者交叉的每一格，装该机构在该主题下写的报告

一句话概括：**矩阵回答「哪里有货」，主题区块回答「说了什么」。**

---

## 2. 范围

### 2.1 本模块包含

1. 一张覆盖矩阵，呈现全部机构 × 全部主题的交叉关系与缺口。
2. 按主题组织的报告卡片，呈现每篇报告的核心信息。
3. 机构、主题、关键词三个维度的筛选与下钻。
4. 数据质量的校验规则与统计口径（篇数、机构数、覆盖数、立场分布）。

### 2.2 本模块不包含

| 不做 | 理由 |
|---|---|
| 自动抓取新报告 | 研报是策展内容。抓取只能拿到标题与摘要，论据必须人写；自动抓取只会得到一堆没有论据的标题。页面上的「刷新研报」只重读本地数据文件并重新校验，不联网 |
| 单篇报告的原文链接 | 公开转载页失效快，留链接比留出处更容易误导。卡片只标来源描述 |
| 行情、股价、估值等实时数据 | 本模块是观点库，不是行情页 |
| 多选筛选、排序切换、收藏、已读标记 | 三个筛选维度已足够；再增加会让「当前在看什么」无法解释 |
| 把立场汇总成「机构情绪指数」 | 见 §3.5 语义边界 |
| 图表（饼图、柱图、词云） | 矩阵本身就是图；再加图会与矩阵争夺同一个结论 |
| 用户编辑、评论、导出 | 内容由策展流程维护，页面只读 |

## 3. 数据范围

### 3.1 三个实体与规模

| 实体 | 数量 | 说明 |
|---|---|---|
| 主题 | **5** | 问题域，固定 5 个 |
| 机构 | **30** | 覆盖 9 个国家/地区 |
| 报告 | **67** | 一篇报告 = 一个「机构 × 主题」单元格的一份内容 |

- 一个单元格可以有**多篇**报告：实测 57 格各 1 篇、5 格各 2 篇。
- 有稿单元格 **62** 个，总格数 **150**（30 × 5），缺口 88 格。
- 收录窗口：**2026-09-01 ~ 2026-11-02**；数据快照日 2026-11-03。

### 3.2 主题（5 个，固定，不可增删）

| 编号 | 名称 | 副标 | 覆盖范围 | 为什么单列 |
|---|---|---|---|---|
| `macro` | 宏观 · 各国经济 | 中 · 美 · 欧 · 日 · 印 | 增长、通胀、央行路径 | 所有资产判断的分母，辖区之间不可互相替代 |
| `market` | 市场 · 股市判断 | 点位 · 盈利 · 风格 | 目标点位、盈利假设、配置与风格 | 唯一能给出「目标点位」这类硬读数的地方 |
| `asset` | 特殊资产 · 配置 | 黄金 · 白银 · 债券 · 信用 | 贵金属、加密、久期、私募信贷 | 定价逻辑与股票不同，混进「市场」会被股票逻辑吞掉 |
| `ai` | AI 产业 | 算力 · 电力 · 应用 | 资本开支、并网发电、芯片产能、应用变现 | 当前最大的单一变量，横跨股/债/商品三条线 |
| `ind` | 其他产业 | 医药 · 消费 · 制造 · 能源 | AI 之外的实体产业 | 剩下的一切，选股逻辑通常先看供给出清 |

### 3.3 机构（30 家，按国家/地区分组）

分布：美国 13、中国 5、日本 3、英国 2、法国 2、加拿大 2、瑞士 1、德国 1、西班牙 1。

**分组规则（硬性）：**

1. 同一国家的机构必须连续排列，不得被其他国家隔断。
2. 国家顺序固定为 **北美 → 欧洲 → 亚太**，洲内按机构数量从多到少。
3. 机构类型（投行 / 资管 / 科技 / 券商）**不参与分组**，只在分组标题后作一行统计，且**仅当该组机构数 ≥ 4 时**才输出（两家时写「投行 2」是噪音）。

设立这条规则的原因：机构补到 30 家后，同一类型里挤着七八个国家，类型这一维的解释力下降——瑞银和桑坦德都是「投行」，但一个用瑞士法郎思考、一个盯着西班牙和巴西。国家这一维可穷举：看到「日本 3 家」就知道这个市场只有三家在说话。

### 3.4 报告字段与约束

| 字段 | 类型 | 必填 | 内容要求 | 长度上限 |
|---|---|---|---|---|
| 编号 | 文本 | 是 | 全局唯一；建议「机构_主题_辖域」，同格第二篇加后缀 | — |
| 机构 | 引用 | 是 | 必须指向机构清单中的一家 | — |
| 主题 | 引用 | 是 | 必须是 5 个主题之一 | — |
| 辖域 | 文本 | 是 | 报告覆盖的地理或资产范围，如「美国」「全球」「新兴市场」「日本」 | 5 字（实测） |
| 日期 | 日期 | 是 | 报告发布日，**不是抓取日**；须落在收录窗口内 | — |
| 标题 | 文本 | 是 | 原文标题的中文改写，非直译 | 27 字（实测） |
| 结论 | 文本 | 是 | 一句话结论，含至少一个数字或明确时点 | **90 字（警告线）** |
| 论据 | 文本列表 | 是 | 1-4 条，每条一句事实 + 一句含义 | 每条 **110 字（警告线）** |
| 立场 | 枚举 | 是 | 偏多 / 中性 / 偏空 | — |
| 关键读数 | 文本 | 是 | 一个可被后续验证对错的读数 | 23 字（实测） |
| 来源 | 文本 | 是 | 机构 + 报告名/日期 +（可选）作者；**不写链接** | 30 字（实测） |

三条约束的意图：

- **上限是护栏，不是目标。** 实测结论最长 66 字、论据最长 76 字，都没顶到线；线只用来拦住「把三段话当结论」的情况。
- **论据条数是硬约束（1-4）**，因为 5 条以上会把同一行的卡片拉高，破坏齐整。
- **关键读数独立呈现**，因为它最容易被误读成投资建议。

### 3.5 立场标签的语义边界

立场（偏多 / 中性 / 偏空）**只描述该报告对它自己覆盖对象的方向**：

- 宏观格里「偏多」＝对风险资产
- 黄金格里「偏多」＝对金价
- AI 格里「偏多」＝对产业景气

三者不是一把尺子。因此：**禁止跨主题比较，禁止汇总成任何「机构情绪指数」或排名。** 全量分布（29 / 31 / 7）只作为数据描述出现，不解读为市场观点。

### 3.6 数据质量规则

数据进入页面前必须校验，分两级：**错误级不通过则不允许出页面**；**警告级只提示，不阻塞**。

**错误级（必须满足）**

| 规则 | 判定 |
|---|---|
| 数据文件存在且可解析 | 不存在或为空即失败 |
| 主题、机构均非空 | 任一为空即失败 |
| 编号唯一 | 主题编号、机构编号、报告编号均不得重复 |
| 必填完整 | 主题需名称与副标；机构需中英文名与国家；报告需标题、结论、辖域、关键读数、来源 |
| 国家合法 | 必须在预定义国家集合内 |
| 国家连续 | 同一国家被其他国家隔断即失败 |
| 引用有效 | 报告的机构与主题必须存在 |
| 枚举合法 | 立场必须是三个取值之一 |
| 日期合法 | 窗口与报告日期均为合法日期 |
| 论据条数 | 必须为 1-4 条 |

**警告级（提示，不阻塞）**

| 规则 | 判定 |
|---|---|
| 机构类型不在约定集合 | 允许未来出现「智库」「交易所」等 |
| 报告日期在窗口外 | 允许窗口边界情况 |
| 结论超过 90 字 | 卡片会被撑高 |
| 单条论据超过 110 字 | 阅读负担过重 |

### 3.7 统计口径

页面上至少 7 处要显示数字（顶部状态、主题区块头、主题导航、机构行尾、筛选结果）。为避免口径分裂，规定：

1. 所有**数据事实**（总篇数、机构数、覆盖格数、各主题篇数与机构数、立场分布）在**数据准备阶段一次性算好**，随数据下发，页面直接读取。
2. 页面**不得自行重算**这些数字，只允许计算「当前筛选结果的条数」这类**视图状态**。
3. 数字定义：

| 指标 | 定义 | 当前值 |
|---|---|---|
| 报告总数 | 报告条数 | 67 |
| 机构总数 | 机构条数 | 30 |
| 有稿机构数 | 至少有一篇报告的机构数 | 30 |
| 主题数 | 主题条数 | 5 |
| 有稿格数 | 去重后的「机构 × 主题」组合数 | 62 |
| 总格数 | 机构数 × 主题数 | 150 |
| 机构覆盖度 | 该机构有报告的主题数 / 5 | 逐家计算 |
| 主题覆盖机构数 | 该主题下不重复的机构数（同格多篇只算一家） | 逐主题计算 |

## 4. 功能需求

| 编号 | 需求 | 说明 | 优先级 |
|---|---|---|---|
| **F1** | 覆盖矩阵呈现 | 以「机构 × 主题」交叉网格呈现全部 30 家 × 5 个主题。行按国家分组，列为主题；每个交叉格显示该组合是否有报告、有几篇 | 必须 |
| **F2** | 缺口可见 | 无报告的格子**必须保留**，不得隐藏或折叠，并与有报告的格子明确区分 | 必须 |
| **F3** | 分组与覆盖度 | 矩阵按国家分组，分组标题显示该组机构数，以及（组内 ≥4 家时）类型分布；每家机构行末显示其覆盖了几个主题（如 3/5） | 必须 |
| **F4** | 按主题阅读 | 报告按主题分区块展示，区块标题含主题名、副标、方法论说明、篇数与覆盖机构数 | 必须 |
| **F5** | 报告卡片信息完整 | 每张卡片必须包含：机构中文名与英文名、辖域、日期、标题、结论、论据（1-4 条）、关键读数、立场、来源 | 必须 |
| **F6** | 按机构下钻 | 点选一家机构后，只显示该机构全部报告，并重置主题筛选为「全部」 | 必须 |
| **F7** | 按组合下钻 | 点选矩阵中任一有报告的格子后，只显示该机构在该主题下的全部报告 | 必须 |
| **F8** | 关键词检索 | 支持在标题、结论、辖域、关键读数、论据全文、机构中文名、机构英文名 7 个字段内检索；不含来源字段 | 必须 |
| **F9** | 三个维度可叠加 | 机构、主题、关键词三者取交集；任一维度可单独使用，也可组合使用 | 必须 |
| **F10** | 筛选状态可见 | 当前生效的机构与主题筛选必须有可见提示，并提供清除操作；另提供「看全部」一键复位（同时清空检索词） | 必须 |
| **F11** | 主题快捷导航 | 提供「全部 + 5 个主题」的导航，每项显示该主题的篇数；点击后定位到对应主题区块 | 必须 |
| **F12** | 空结果处理 | 筛选后无结果时，给出明确提示（当前筛选下没有报告，可点「看全部」恢复），矩阵与导航保持可见，避免让人误以为数据缺失 | 必须 |
| **F13** | 数据缺失降级 | 数据未就绪时不展示半成品页面，明确提示数据不可用；单个主题的方法论说明缺失时，不影响其余内容展示 | 必须 |
| **F14** | 只读 | 页面不提供任何写入、编辑、评论、导出能力 | 必须 |

### 4.1 行为说明（F6-F11 的细则）

1. **下钻后定位**：点选主题或格子后，页面应定位到对应主题区块的起始位置，便于接续阅读。
2. **再次点选取消**：点击已选中的机构名，应恢复为「全部机构」。
3. **检索不改变矩阵**：输入检索词时只更新卡片区与结果计数，矩阵的选中状态保持不变——矩阵表达的是覆盖事实，不随检索变化。
4. **清除只清筛选**：清除按钮只重置机构与主题，保留检索词。
5. **导航与矩阵联动**：通过导航选择主题时，矩阵中对应列的有稿格子应同步显示为选中状态，使人知道当前看的是哪一列。

## 5. 非功能需求

| 编号 | 需求 | 判定 |
|---|---|---|
| N1 | 离线可用 | 断网状态下完整可用，不依赖任何外部资源 |
| N2 | 数据单一来源 | 修改数据文件并重新加载后，页面内容随之变化，无需改代码 |
| N3 | 规模可承受 | 30 行矩阵与 67 张卡片在常规设备上首次呈现无明显等待 |

## 附录 B · 内容撰写要求

本模块的说服力集中在「结论」与「关键读数」两行，写法有硬要求。

### B.1 结论

| 不合格 | 问题 | 合格 |
|---|---|---|
| 「我们认为市场短期仍有波动，中长期看好。」 | 无数字、无时点、不可反驳 | 「三季度 EPS 同比 33%，但加速已经到顶；2027 年增速降到 18%，仍足以支撑第四年两位数回报。」 |
| 「该机构对黄金持乐观态度。」 | 转述立场，无理由 | 「实际利率见顶后金价中枢上移到 4200，央行购金是需求端最确定的一块。」 |
| 三段话塞进一个字段 | 卡片被撑高，破坏版面 | 1 句结论 + 2-3 条论据 |

要求：

1. 含至少一个数字或明确时点（`18%`、`12 月`、`2027 年`）——没有数字的判断无法核对。
2. 不写「我们认为」「我们维持」「看好/看空」这类评级套话，立场交给立场字段。
3. 读完后能知道「比市场预期高还是低」。
4. 中文标点，不使用表情符号与感叹号。

### B.2 论据

- 结构：先一句事实（可核对），再一句含义（为什么重要）。
- 三条最合适：一条给分母（宏观/行业数据）、一条给结构（谁在贡献）、一条给风险（哪里会错）。
- 不重复结论的话；不写免责声明。

### B.3 关键读数

必须是一个**可被后续验证对错**的读数：目标点位、增速、利率水平、时间点。如「标普 500 目标 6800」「美联储 12 月 +25bp」「新增用电需求 40GW」。
不合格：「看好」「超配」「中性偏多」——这些是立场，立场字段已有。

### B.4 来源

格式：机构 + 报告名/日期 +（作者）。不写链接。若来自访谈而非报告，标注「访谈」。

## 附录 C · 术语表

| 术语 | 含义 |
|---|---|
| 主题 | 问题域（宏观/市场/特殊资产/AI/其他产业），不是行业分类 |
| 格 / 单元格 | 一个「机构 × 主题」组合；150 格中 62 格有稿 |

| 覆盖度 | 某机构触及了几个主题，如 3/5 |
| 收录窗口 | 报告日期允许范围，当前 2026-09-01 ~ 2026-11-02 |
| 辖域 | 报告覆盖的地理或资产范围 |
| 立场 | 偏多 / 中性 / 偏空，只对该报告自身的覆盖对象有效 |
| 关键读数 | 报告中最容易被误读成建议的硬读数，独立呈现 |
| 策展内容 | 人写、入库、随版本更新的内容，区别于自动抓取流 |
| 下钻 | 从矩阵格子或机构名进入对应报告列表 |
